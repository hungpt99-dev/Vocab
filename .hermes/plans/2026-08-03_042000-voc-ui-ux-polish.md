# VOC UI/UX Polish — Library Icons + Visual Refresh Implementation Plan

> **For Hermes:** Use subagent-driven-development (or the CodingAutomation worker) to implement task-by-task. Linear is the source of truth — each child issue is a unit of work.

**Goal:** Make the ai-vocab-saver Chrome extension's UI/UX more beautiful and consistent, sourcing every icon from the `lucide` library (never emoji, unicode glyphs, or hand-inlined SVG paths), and verify all features still build, typecheck, and pass tests.

**Architecture:** Two icon surfaces exist today and both must move to lucide:
1. **React UI** (`src/shared/ui/Icons.tsx`, popup + options) — already imports `lucide-react` but keeps a `GLYPHS` char-glyph fallback map + a font-health probe. Replace the char fallbacks with the real lucide SVG (lucide-react bundles SVG, needs no web font).
2. **Content script** (`src/content/icons.ts` + inline `wrap()` SVGs in `toolbar.ts`, `selection-popover.ts`, `explain-panel.ts`, `explain-popover.ts`) — hand-copied lucide path data. Replace with `lucide-static` (library-shipped raw SVG path strings) consumed by a small `icon()` helper, so paths are maintained by the lib, not copy-pasted.
Then a visual-refresh pass standardises spacing/radii/colour/focus across toolbar, popovers, explain panel, reading-mode, popup, options. Finally a verification gate (typecheck + dual build + 397 tests + smoke checklist).

**Tech Stack:** TypeScript, Vite (dual build: app + content IIFE), Tailwind CSS, `lucide-react` (already a dep), add `lucide-static` for the content script. Chrome MV3.

## Risks / tradeoffs
- `lucide-static` ships ESM; the content build is an IIFE via Vite — importing named icon strings works (they're plain strings). Verify the content bundle still builds.
- Removing the font-health fallback in `Icons.tsx` is safe because lucide-react emits inline SVG (no icon font), but keep `aria-label`s so controls stay accessible if SVG is blocked.
- Don't change message/protocol types in this effort — pure presentation.
- Keep `ToolbarState`/`SelectionPayload` shapes stable so existing tests pass.

## Definition of Done
